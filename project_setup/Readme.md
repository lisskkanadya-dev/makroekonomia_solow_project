# Solow Model and Convergence Test

This project is a lightweight Python web project for an academic empirical task. It downloads GDP per capita data, calculates growth rates, tests beta-convergence and sigma-convergence, generates charts, and builds a static HTML report.

The generated report can be deployed with GitHub Actions to GitHub Pages.

## Research Question

Do empirical data confirm the Solow model prediction that poorer countries grow faster and income differences between countries decrease over time?

## Main Features

- Downloads GDP per capita data from the World Bank API.
- Supports offline CSV data for testing and reproducibility.
- Calculates average annual GDP per capita growth using CAGR.
- Tests beta-convergence with a cross-sectional regression.
- Tests sigma-convergence using dispersion of log GDP per capita.
- Generates PNG charts.
- Generates a static `site/index.html` report.
- Can be deployed to GitHub Pages through GitHub Actions.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run with Live World Bank Data

```bash
python -m src.solow_app --countries POL DEU CZE SVK HUN ROU BGR UKR ESP PRT --start-year 2000 --end-year 2023 --output-dir site
```

Expected result:

```text
site/index.html
site/gdp_per_capita.png
site/beta_convergence.png
site/sigma_convergence.png
```

## Run with Offline CSV Data

Offline mode is useful for tests or when the API is unavailable.

CSV format:

```csv
country_code,country_name,year,gdp_per_capita
POL,Poland,2000,10000
POL,Poland,2020,20000
DEU,Germany,2000,40000
DEU,Germany,2020,50000
ROU,Romania,2000,5000
ROU,Romania,2020,18000
```

Run:

```bash
python -m src.solow_app --offline-data data/sample.csv --output-dir site
```

## Run Tests

```bash
pytest
```

Network calls should be mocked in unit tests. The test suite should not depend on the live World Bank API.

## GitHub Pages Deployment

The intended deployment target is GitHub Pages.

The GitHub Actions workflow should:

1. install dependencies,
2. run tests,
3. generate the static report,
4. upload the `site/` directory,
5. deploy it to GitHub Pages.

The final result should be available as a public static web page.

## Data Source

Recommended source:

- World Bank API
- Indicator: `NY.GDP.PCAP.KD`
- GDP per capita, constant 2015 US dollars

## Notes for Developers

The project should stay simple. It does not need a database, backend server, or JavaScript framework. The main deliverable is a reproducible static report generated by Python.

Code comments should be short and written in plain English.
